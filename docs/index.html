RSI Overlay for TradingView

A free Chrome extension that overlays live RSI(14) on your TradingView charts.

Get it on the Chrome Web Store View source on GitHub

What it does

  • Shows a live Wilder RSI(14) reading directly on the chart — no separate indicator panel needed
  • Set your own oversold / overbought thresholds
  • Get a browser notification the moment a symbol crosses into oversold or overbought territory
  • Drag the overlay anywhere on the chart; it remembers where you put it
  • No account, no sign-in, no broker connection required
